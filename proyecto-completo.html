Mapa maestro del ecosistema

PROYECTO
COMPLETO

Nómada Extremo no se plantea como una sola actividad, sino como un ecosistema completo de aventura, formación, seguridad, naturaleza, contenido audiovisual y comunidad.

Explorar áreasVer intermodularMarco académico
Cómo leer esta web: la portada seduce y orienta, las páginas principales explican, y las páginas profundas demuestran con fichas, seguridad, formularios, rutas, material, escuela, logbook y documentación. Este mapa existe para que la amplitud del proyecto se entienda como una arquitectura, no como acumulación.
